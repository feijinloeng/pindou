# 1:1 打印承诺"精确毫米 + 校准尺 + 跨页对位十字"

纸面版制作文档用矢量 PDF 输出，页内每格严格等于针距（2.6mm / 5mm）。每页印一把 10mm 校准尺让用户当场量，跨页处让相邻两页共享一条几列豆宽的重叠带并印对位十字，靠对齐标记而非裁纸拼接。

理由：矢量 PDF 的毫米本身是精确的，误差只剩打印机缩放（用户可控）和纸张定位（±1mm，不可控）。重叠带让纸张定位误差不逐页累积。不承诺"实测回填补偿"是因为它需要一个额外闭环 UI，且只在用户量出标称针距与实际针距有偏差时才有价值 —— 那是下一位。

## Considered Options

- **只保证毫米正确，页面写死"按 100% 打印"**：最便宜，但用户打印机缩放错了就直接翻车，且我们没有补救手段。
- **加实测回填补偿（用户量出 10.3mm 就填回工具重新生成）**：最准，能消掉真板针距与标称值之间的偏差，但要多做一个闭环 UI。
- **精确毫米 + 校准尺 + 重叠带对位十字** ← 选定。

## Consequences

A4 可打印区域（约 200 × 287mm）除以 2.6mm 得每页约 76 × 110 豆，因此一块 104 钉板必然跨页、一块 78 钉板也跨页、只有 52 钉板能一页装下。所以跨页对位不是边界情况，是常态，必须第一版就做对。
