# 板阵按针距建模，而不是按整块板

板阵的坐标系统一建立在**针距**（2.6mm 或 5mm）之上：每块板向阵列贡献自己的钉数，所有板共享同一根针距轴，不把"整块板"当作排版单位。因为 104 = 2 × 52 所以两者天然互通，而 78 = 52 + 26 所以 78 必须配一块 26 钉补角板才能在阵列里收口 —— 这两条物理事实按整块板建模都得靠特例代码表达。代价是需要一层板阵合法性校验，且板阵面积可以堆很大，必须另设上限。

## Considered Options

- **只允许同尺寸板拼接**：最稳，但覆盖不了 78 和混合阵列，也浪费了 104 = 2 × 52 这个白送的能力。
- **毫米级自由拼接（用户自填钉数与间隙）**：最灵活，但用户极易填错，还要处理非整数格和非标准针距的渲染。
- **共享针距的钉数建模 + 固定板型枚举（26 / 52 / 78 / 104 / 29）** ← 选定。排布自由，合法性可校验。

## Consequences

板缝必须由板阵推导出来，不能由用户手画。板型枚举是唯一合法的排布单位，因此新增板型是改数据不是改逻辑。
